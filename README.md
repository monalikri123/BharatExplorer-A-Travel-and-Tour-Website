# BharatExplorer-A-Travel-and-Tour-Website
A fully responsive, interactive travel and tour website built using HTML, CSS, and JavaScript. This project showcases tour packages, categories, and a functional contact form, offering users a seamless and visually engaging experience.

## 📌 Project Overview

 BharatExplorer is a front-end project that simulates a travel and tour booking portal. It features a modern layout with sections for destinations, packages, and user interaction. The site is responsive across all devices and provides a base for integrating backend functionality in the future.

---

## ✨ Features

- 🔍 Responsive Sticky Navigation Bar  
- 📸 Hero Section with Full-screen Background  
- 🧳 Travel Categories with Interactive Hover Effects  
- 🏝️ Tour Packages with Pricing and Details  
- 📬 Contact Form for User Inquiries  
- 💡 Clean UI/UX Design with Smooth Transitions  
- 💻 Mobile-Friendly & Cross-Browser Compatible  

--

## 🛠️ Technologies Used

- **HTML5** – Structure of the website  
- **CSS3** – Styling and responsive layout  
- **JavaScript** – Interactivity and dynamic elements  
- **Google Fonts** – Typography (Poppins)
